🚀 アプリケーションの概要

nsfw-checker-pro は、7つの独立したAIエンジンを組み合わせた、最高峰の画像分析ツールです。 2026-07の刷新で実写タガーと4段階重大度分類器を追加し、圧倒的な精度と信頼性を実現しました。

NudeNet v3 (640m)

露出部位の物体検出に特化したエンジン。わいせつな部位を正確に特定し、座標情報を取得します。高精度640mモデルを自動選択。

WD14-Tagger V3

1万以上のタグを認識。服装（下着・水着等）やシチュエーションを詳細に分析。公式レーティング(general/sensitive/questionable/explicit)も活用。

[NEW] Photo Tagger

idolsankaku-eva02タガー。WD14がアニメ調に偏るのを補完し、実写(グラビア/アイドル系)のタグ・レーティング精度を強化します。

[刷新] ViT NSFW (Freepik EVA02)

neutral/low/medium/highの4段階重大度分類。旧Falconsaiの二値判定より高精度・高粒度です。

Anime/Real Classifier

アニメ調か実写かを判定し、スタイル別のスコアリング調整に利用します。

LFM2.5-VL

ローカルVision-Language Modelによる文脈理解型の安全性判定。SNS投稿文の自動生成にも活用。

Vision API

Google Cloud の SafeSearch を統合。クラウドとローカルのハイブリッド判定が可能です（任意/APIキー要）。

🏗️ システムアーキテクチャ (UML)

本アプリは、疎結合なモジュール設計を採用しており、エンジンの追加やメンテナンスが容易です。 各エンジンは共通のインターフェースを備え、Analyzer がそれらを統括して並列実行します。

🎮 使い方

  • 起動: 同梱の run.bat をダブルクリックして起動します。
  • 追加: フォルダ選択またはファイル選択で画像をリストに追加します。
  • 解析: 「スキャン開始」ボタンで全エンジンの同時分析が始まります。
  • 確認: リストを選択すると、右側に詳細な分析スコアとプレビューが表示されます。
  • 保存: CSV, JSON, または HTMLレポートとして結果を出力できます。
